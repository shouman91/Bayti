# bayti-customer-ops

هذه مهارة خاصة بمستودع Bayti؛ الموارد محسوبة من جذر المستودع. اقرأ AGENTS.md وknowledge/bayti-brief.md ثم workflows/customer-ops.md. اختر فقط ملفات الأدوار اللازمة من: employees/publisher.md، employees/community.md، employees/sales-coordinator.md.

ابدأ بالمخرج المطلوب والأصول والمعلومة المؤكدة. استخدم القالب الأنسب تحت templates/ وسلّم ملفًا أو نتيجة فعلية، مع الأدلة والحالة والناقص والخطوة التالية. احفظ بيانات العميل والفواتير والنتائج الخاصة تحت private/.

تخصص بيتي: رقم صفحة الكتالوج ليس SKU؛ المخزون والأسعار لا تثبت من الكتالوج؛ حافظة البقوليات ص26-27 مختلفة عن بلت إن ص43؛ خدمة القياس لها تأهيل ونتيجة مختلفة عن بيع المنتجات. ارجع لـknowledge/brand.md للتصميم، وknowledge/operating-agreement.json للفوترة والنطاق.

إعداد الدور أو قراءة هذه المهارة لا يثبت الاتصال أو يشغل خدمة دائمة أو يمنح إذن نشر أو إرسال أو صرف. احترم التفويض الموجود، ولا تطلبه مجددًا إذا كان يغطي نفس الإجراء. لا تخلط اقتراحًا سابقًا للمساعد مع اتفاق العميل.
