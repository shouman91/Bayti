# موظفين بيتي | BAYTI Agency

طاقم وكالة ذكاء اصطناعي مخصص لبيتي فقط: **22 دورًا** من المدير إلى الإنتاج والإعلانات وخدمة العملاء والمحاسبة. نقطة تواصلك **نديم مدير الوكالة**. لكل دور مسؤوليات ومدخلات ومخرجات ومعايير قبول وتسليم للزميل التالي.

**الأتعاب المؤكدة: 450 USD شهريًا للوكالة كاملة.** ميزانية الإعلانات منفصلة. فترة بدء الخدمة وعدد التسليمات وشروط الاستحقاق والضريبة لم تُحسم بعد. الخبرة 25+ سنة معيار جودة وحكم مهني مستهدف للأدوار، وليست سنوات عمل فعلية أو ضمانًا للنتيجة.

## طريقة الشغل

«يا نديم، جهّز شغل الأسبوع لبيتي من المنتجات المتوفرة، وارجعلي بالتسليمات والناقص الضروري». المدير يختار الأدوار اللازمة ويجمع النتيجة. لكل موظف الآن مهارة أساسية وملف معرفة خاص: **22 مهارة متخصصة و6 مهارات مشتركة، المجموع28**. [مصفوفة الموظفين والمهارات والمعرفة](knowledge/role-skills-matrix.md) توصل إلى الملفات؛ إن لم تظهر المهارات تلقائيًا تُقرأ مباشرة، دون افتراض تفعيل عالمي.

التسليم بين الأقسام يشمل الملفات المستهلكة والمخرجات وأدلة التحقق، مع كشف النسخ القديمة وإعادة العمل. [عقد التسليم](contracts/handoff.md)، [مطابقة المنتج بالتصوير](knowledge/product-identity.md)، [حدود الأدوات](knowledge/tool-capabilities.md)، [مصادر المعرفة](knowledge/source-library.json).

الأساس مستند إلى حساب @baytihome.ps والكتالوج (164 صفحة) ودليل الهوية ومحادثات بيتي المتاحة. [عينة المنتجات](data/catalog-seed.csv) تضم 15 مرجعًا وليست مخزونًا حيًا. [مسار التشغيل](workflows/agency.md)، [المنتج إلى البيع](workflows/product-to-sale.md)، [الإقفال الشهري](workflows/monthly-close.md)، [أول أسبوع](workflows/first-week.md).

## التشغيل والتحقق

Python 3.10+، بلا حزم خارجية لأدوات التشغيل:

```text
python scripts/verify_team.py
python -m unittest discover -s tests -v
python scripts/check_all.py
python scripts/ops_math.py tests/fixtures/agency-case.json --out private/demo/report.json
python scripts/finance.py --period YYYY-MM --out private/invoices/
```

أمر المالية ينتج مسودة JSON داخلية فقط ولا يرسل فاتورة. لا توجد خدمة AI/API أو مهام مجدولة تعمل بالخلفية؛ التنفيذ يتم عند طلبك في البيئة المتصلة. ملفات التعليمات لا تثبت توصيل حساب أو نشرًا أو مونتاجًا أو محاسبًا قانونيًا.

بيانات tests/fixtures/agency-case.json مصطنعة لاختبار CRM والحملات والمحاسبة، وليست نتائج بيتي أو مبيعاتها. check_all يعيد فحص الهيكل والحسابات والتبعيات محليًا؛ لا يعيد تلقائيًا جلسات النماذج أو إنتاج الوسائط. نتائج الاختبار السلوكي وحدودها في [تقرير التحقق](VALIDATION.md)، ومعاييره في [دليل الاختبار](tests/behavioral-rubric.md).

المستودع عام. البيانات التشغيلية الحساسة في private/ المحلي المتجاهل؛ هذا ليس تخزينًا مشفرًا أو مشتركًا بين الأجهزة، ولا يُنقل تلقائيًا إلى Cloud. ارفع فقط البيانات اللازمة عبر وجهة خاصة مصرح بها عند الحاجة. القوالب العامة لا تحتوي بيانات عملاء أو دفعات فعلية.
