# بيانات التشغيل

catalog-seed.csv عينة مرجعية من 15 منتجًا وليست استيرادًا كاملًا أو مخزونًا حيًا. CAT-xxx معرف مرجعي داخلي للصفحة، وليس كود بيتي. راجع الصفحة والموديل قبل الاستخدام.

الأسعار والتوفر والمقاسات الفنية التفصيلية تؤكد من العميل قبل إعلانها. بيانات CRM والمصروفات والفواتير الفعلية تُحفظ تحت private/ فقط. القوالب العامة فارغة عمدًا.
