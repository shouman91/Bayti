# ربط الأدوات بقدرات الأدوار

ملفات المهارات تنقل طريقة العمل والمعرفة؛ الأداة الفعلية يحددها المضيف وقت الطلب. لا تذكر موصلًا متاحًا دون فحصه.

| الدور | يستطيع محليًا | التنفيذ الذي يحتاج أصلًا أو اتصالًا |
|---|---|---|
| البحث والمنتج | قراءة الكتالوج ومصادر عامة وإعداد بطاقة | مخزون وأسعار حديثة من بيتي |
| النص والإخراج | سكربت وموجز وخطة لقطات | التصوير الميداني يحتاج شخصًا ومعدات |
| التصميم والموشن | HTML/SVG/صور معاينة وتوقيت | أصل المنتج والشعار والخط وأداة معاينة |
| المونتير | تعديل وتصدير من وسيط وأداة متاحين | لا فيديو بلا وسيط، ولا فحص سمعي دون استماع |
| النشر والإعلانات | حزمة وتوصية وتحليل ملف | النشر/الإعلانات تحتاج حسابًا متصلًا وتفويض الإجراء |
| الخدمة والمبيعات | مسودات وردود وCRM محلي | الإرسال والوصول الخاص ضمن التفويض |
| المالية | حسابات ومسودات ومطابقة من أدلة | لا مصرف أو تحصيل تلقائي، ولا ضريبة مفترضة |
| الهندسة والجودة | أدوات وفحوص وإعادة بناء | الاختبار المحلي لا يثبت تفعيل Cloud |

scripts/ops_math.py لحساب بيانات اختبار/تشغيل من عقدها، scripts/finance.py لمسودة الأتعاب، scripts/handoffs.py لتتبع الدليل. تحقق من الأدوات قبل اختيار مسار ChatCut أو FFmpeg أو أداة أخرى؛ لا تعد بوجودها في بيئة جديدة.

لتعيين مصادر البيئة، استخدم templates/source-locations.json كنموذج لـprivate/source-locations.json. المسارات الفعلية خاصة ولا تُرفع، ويلزم التحقق من وجودها في كل بيئة. إشارة source-library إلى كتالوج لا تعني أن الملف متاح في Cloud.
