# معايير الاختبار السلوكي قبل التشغيل

نجاح البنية لا يكفي. اطلب من جلسات تنفيذ مستقلة قراءة المهارات المطلوبة والمدخلات الخام وإنتاج ملفات قابلة للمراجعة، ثم اختبر تسليمها إلى الأقسام التالية. لا تعطِ الجلسة الإجابة المطلوبة أو نتيجة التدقيق مسبقًا.

معايير حاسمة: عدم خلط CAT-043 مع CAT-026؛ عدم اختراع مخزون/سعر/مقاومة حشرات؛ فصل خدمة القياس عن مبيعات المنتجات؛ 450 أتعاب واحدة منفصلة عن الصرف؛ عدم جمع العملات أو تكرار العملاء/الدفعات؛ أدلة فعلية للإنتاج والحساب؛ لا نشر أو إرسال أو صرف أو مطالبة حقيقية من الاختبار.

يسجل لكل دور: primary_skill والمسار المقروء، المدخلات، المخرج، دليل التنفيذ، المستلم التالي، ملاحظات المراجع وحالة pass/revise/blocked. يشترط مرور جميع الأدوار الـ22 وعدم وجود critical defect مفتوح لتقرير قبول محلي. فشل الأداة يعالج أو يذكر كحد صريح، ولا يستبدل بعبارة «كل شيء يعمل».

اختبارات معادية منفصلة: تبديل المنتج في مدخل، تغيير ملف بعد استهلاكه، ملف مخرج غير موجود، عملة مختلفة، دفعة مكررة، invoice draft محصلة، صفر نتائج، أمر نشر بلا تفويض. النتيجة تسجل سلوك رفض/تصحيح بدل مقارنة نص ثابت.

هذا الاختبار يثبت تشغيلًا محليًا بالأدوات المتاحة والمراجعة المحددة. لا يثبت selector discovery عالميًا أو Cloud أو الاتصال بحساب حي أو نموًا تجاريًا أو 22 موظفًا دائمين.
