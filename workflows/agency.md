# من الطلب إلى التسليم

نديم يقرأ الطلب وملف بيتي ويحدد الهدف والمخرج والتفويض. دانا تسجل مهمة وموعدًا. اختيار الأدوار حسب الحاجة: كابشن بسيط لا يحتاج 22 موظفًا. يعمل المساعد بالأدوار بالتتابع داخل المهمة؛ لا يدعي أن أشخاصًا مستقلين اجتمعوا أو راجعوا العمل.

للمحتوى: يوسف يؤكد المنتج → ليان/ليث يجهزان الموجز عند الحاجة → عمر يكتب → رامي وسامر يحددان التصوير → حسام وزيد ونور ومالك ينتجون بحسب الأصل → رنا تفحص → ميرا تجهز أو تنشر ضمن التفويض → سارة تقرأ النتائج → نديم يعيد قرارًا واحدًا للمستخدم.

للاستفسارات: هبة تؤهل → أحمد يتابع العرض والطلب → يوسف يحسم التوافق → النتيجة المؤكدة تذهب لسارة. بيع المنتج وحجز القياس لهما سجلان أو نوع واضح.

للمحاسبة: ريم تعد المسودة من الفترة والبيانات → باسل يطابق الإثبات → فادي يراجع الأتعاب والتكاليف → نديم يعرض الاستثناء فقط. لا إرسال أو تحصيل من مجرد تجهيز المسودة.

راجع ملاءمة المنتج والدليل والتكلفة قبل جمال المخرج. كل تسليم يستخدم templates/handoff.md. ملف تعليمات أو قالب لا يساوي تنفيذًا حيًا؛ اذكر دائمًا ما حصل فعلًا.
