# الإقفال والفوترة الشهرية

أتعاب الوكالة المؤكدة: 450.00 USD لكل شهر خدمة، مرة واحدة للوكالة. لا تضربها بعدد الموظفين، ولا تخصم أو تضف ميزانية إعلان تلقائيًا.

اجمع الفترة وبيانات المورد وشرط الاستحقاق والمعاملة الضريبية من المصدر. لم يحدد المستخدم بعد بداية الفوترة أو الضريبة أو اسم الجهة المصدرة؛ لذلك الناتج الافتراضي مسودة داخلية لا فاتورة ضريبية أو مطالبة مستحقة. لا تفترض ضريبة صفرًا.

ريم تبحث في السجل عن الفترة لمنع التكرار، وتعد المسودة. باسل يطابق الدفعات بإثباتها مع الفاتورة نفسها. فادي يراجع التكاليف الموثقة منفصلة عن الأتعاب وعن مبيعات بيتي. سجّل حالات draft/issued/partially_paid/paid/void، وتأخر السداد فقط بعد موعد استحقاق معروف.

الأداة المحلية: python scripts/finance.py --period YYYY-MM --out private/invoices/ . تنشئ JSON داخليًا بحالة draft، ولا تصدر أو ترسل أو تخصم مالًا. التحويل بين العملات يحتاج سعر صرف ومصدر وتاريخ؛ لا تضم العملات المختلفة في إجمالي واحد.

الحفظ الفعلي وبيانات البنك والعميل تحت private/ المتجاهل. الإقفال يخرج مراجعة خدمات وتسليمات وتكاليف وإثباتات، لا مجرد رقم مبيعات أو ربح متوقع.
